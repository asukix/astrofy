## Creation and destruction
When I am trying to understand the thinking space, I am creating my own mental model. This is quite easy. The hard part for me the destruction of the model. I found sometimes the destruction can be also quite easy.

## Difficulties in destruction
I noticed 2 type of difficulties while I was rebuilding my mental model:
1. When I create my mental model from scretch with understanding the problem space.
2. When I used a model that I learnt but it not realy mine.

### Destruction of my realy own mental model
When I build my mental model from ptoblem space is so hard for me to destroy it. It is hard because I made it. I spent **a lot of time to understand the problem and create a solution.** This process make hapiness and after this I feel: ok I am done, this is looks good and this is that I made. And thats why I feel this is mine and thats why the destruction is hard, and that's why I don't want to do it. But if I do It the new model usually better because my understanding improved.

#### Destruction example
Lets give a real word example. If I create a lego house that I imagine. I can build it and I enjoy the building of the house. When it is ready it feels good, but the building was the most enjoyable part. After that I don't want to destroy it. But when I do it and rebuild again it will be better and I also can feel the hppyness of the building

### A built in mental model
A ** built in model for me** is that:
- I learnt something and I used it a lot of time and 
- I used it as a base, and 
- I build new things on top of it.
But it is a learnt built in model not my really own model. 

#### Difficulties in destruction of a built in mental model
When I try to understand a built in model's background and it's problem space I try to make my own solution. At this situation I noticed I use my old understanding and I just recreate a very similar model. And this is the hard part, because I can't forget the solution that I learnt earlier. It is good because I can understand the model better but it is hard, because it is not my own model. That is not a problem. We can use others model bacuse we don't have time to rebuild everything from scretch. The problem is that when I want to create my own mental model from a built in one.

## Make the destruction easier
What I love in Thinking Space System is that I have time thinking and I have time:
- to understand the problem and 
- make my own solution. 

### Using questions
During this process my most powerful tool is asking questions. I found when I stucked with destruction, questions helps me. The interesting thing here: the more questions make more curiousity that creates more questions. And this process help me to change my mind. With this I don't concentrate realy to the destraction even in building. And the building process automatically destroys the old model. I mainly use it with my own mental models, but this is working with built in models as well.

#### Architecture example
Let check an architecture example together with MVVM. And let me add very short answers because of the example. MVVM is the Model View ViewModel. *But what is the model?* The model is the place of the business logic. And here some more questions as example:
- What is the difference between the model and the model in view model? - The model in view model shouldn't contain business logic or calculation.
- How I connect the model, the view and the view model? - One connection is that the View contains the VM and the VM contains the Model.
- Is there other elemts in the MVVM? - Yes, the converter that can be used by the View.

### Explanation and structed thinking
When I try to rebuild a built in model, it also hard to me. I noticed something during:
- I shared my thoughts and 
- I was writing my own articles. 
When I try to explain something it, helps me to find my gaps. And it also help me to try to understand the problem again and that indicates to rebuild my model. 

#### Rebuild your built in model
Have you ever tried to explain something to someone and found the issue that person didn't undersand it? What I did here that I tried to explain it from a different aspect. And this helps me to also rebuild my understanding. And this is also an enjoyable way, because I can make my brain to work. So I give problem to it. And this time the destruction is easier to me. 
I usually use this technique for built in models, but it is also good for rebuilding my own mental models as well.

## Recap

### Learnt model vs built model
I found an important dinstinction between a learnt model and a model that I built from scretch. If I build my mental model, I can rebuild my solution anytime. So it can be easy to change it. This means it can evolve. When I use a learnt model I can just use it and I had to remember to it. I can't build it. I can't evolve it. And tell the truth I feel that **I don't realy understand it.** That's why I prefere my own models.

### Make it easier
The destruction of a mental modal not so easy because I feel it is mine or already built in. The queions raised because of curoiusity or different approach of the problem helps me to make it easier.
