## When creation is hard
When I start thinking in a problem space that I don't know, that time quite easy to asking question and making own mental models. When we read a definition we get an existing mental model that is from others. This is the easyest way and it is ok most of the time, as we usually need a lot of information rapidly. When a mental model is already build in and used it is hard to rebuild it. You will try to use those definitions and understanding when you will try to recreate it.
