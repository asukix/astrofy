When a topic is well-defined, I think we can create a sentence about it that summarizes the topic well. So I guess that if something needs to be explained at length, and not for the sake of clarity, then it is either not a well-organized system, or it is actually more than one thing.
Feynman had a thought experiment in which he asked if we had to convey the least amount of information in the fewest words, what would that information be?
Here I would like to note that I think the knowledge of humanity is quite diverse and large. So I think that it is easier to cover individual areas with 1-1 such sentences than the whole thing. And this is where it gets interesting for me. Because we don't want to learn just one thing. By nature, we are curious, like a child, and we like to ask questions. Somewhere during adulthood, we learn the benefits of quick information. In our fast-paced life, we are given things ready-made that we can easily access. So, we usually don't make bread from sowing wheat to making ready-made bread, but often we don't even bake bread from ready-made flour. In today's world, this is natural. In this world, sometimes it takes awareness to stop and look at things more closely and ask questions. When we get a simple definition, we think we understand it because the words they use are understandable, but that doesn't mean we really understand it. Let me give you an example. For example, if I say that a YouTube channel is a tool for providing video services where we can post content and users can subscribe to it, I think that's understandable. But what is a subscription? When we subscribe, we get notifications about new videos. Okay, but how exactly does a subscription work? And then here you can explain the observer pattern. And when I ask how it works, there's its logic or code. And the questions could go on for quite a long time, even to the basics of computers. So time is important for understanding: how much time I want to spend on understanding something. If I'm just interested, then a simple definition is good. If I'm more in-depth, then I start to understand how it works.
So we have
- a hypothesis: the one-sentence description itself.
- and we have a tool: questions
- if we add a context to it, then we get a system
Let's organize it. I say that if we are interested in a topic, let's ask, let's understand. This will be the curiosity itself that brings a good understanding by creating a mental model. Once we understand, let's try to define it in an Open Sentence. The sentence should be explicable and questionable, so that if someone hears or reads it, they can ask questions. This is how we learn, we understand. The Open Sentence helps validate our understanding and is also a tool with which we can pass on the fruits of our own work to others. Curiosity, understanding and the opportunity for others to enjoy this process
